# Razo Sprinkler Repair

Single-page website for Razo Sprinkler Repair, sprinkler repair and yard cleaning in North Las Vegas, Nevada.

- Everything is in `index.html` (inline CSS and JS, Google Fonts). Open it in any browser; no build step.
- The hero animation (a sprinkler rotor at dusk) is drawn on a canvas and respects reduced-motion settings.
- The request form opens a prefilled text message to (702) 542-8308. Replace that handler once a real form destination exists.
- Search the HTML for `OWNER:` to find details that still need confirming (rating, service list, service area, privacy links, domain).
